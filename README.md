# 🏝️ 數學島 Math Island

在 3D 六角形群島上邊玩邊學數學的互動網頁遊戲。每個大單元是一片群島，每個任務對應均一教育平台的一個小單元，過關可以賺「因數幣」買新外觀。

**▶ 開始玩：<https://twtimothylu.github.io/math_island/>**

## 目前的單元

### 因數群島：六上 第一單元「最大公因數與最小公倍數」

均一課程：<https://www.junyiacademy.org/topics/h-m6a-c01>

| 🐚 1-3 公因數海灣 | 公因數、最大公因數、互質 |
| ⛄ 1-4 公倍數雪山 | 公倍數、最小公倍數 |

| 🏰 中央島 | 期末試煉塔（完成 18 個任務後開放）、方塊商店、換裝屋、任務佈告欄 |

## 玩法

- 第一次進入時先取名字、打扮角色。五官可以用畫筆直接畫在臉上。
- 點地面或用 WASD／方向鍵走路。靠近設施後按 **E** 或點設施，就能開始任務。
- 每個任務會先介紹概念，再進入小遊戲。依答對的比例拿 1～3 顆星和因數幣。
- 完成上一座島足夠的任務，下一座島的橋才會打開。
- 到「方塊商店」試穿、購買外觀，到「換裝屋」搭配自己擁有的衣服，還可以存成 3 組搭配。

## 給老師

- **老師模式**：右上角 ⚙️ 設定 →「老師模式」，會直接開放全部島嶼，方便預覽每個任務。
- **存檔**：進度存在學生自己的瀏覽器裡（localStorage）。換裝置、清除瀏覽器資料或用無痕模式時，進度不會帶過去。
- 不需要登入，也不會收集任何個人資料。

## 在自己電腦上執行

直接雙擊 `index.html` 就能玩。也可以開一個本機伺服器：

```bash
python -m http.server 8123
```

然後打開 <http://localhost:8123>。
